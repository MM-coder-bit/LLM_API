# LLM_API
Desenvolvimento e Deploy de Modelos de Machine Learning, visa desenvolver e implantar uma API  que utiliza Modelo de  Linguagem de Grande  Escala  (LLM)  para  gerar  texto  a  partir  de  imagens.  Vou construir  a  API  e  então implantá-la em um container Docker que poderá ser executando independente de plataforma, local ou na nuvem
